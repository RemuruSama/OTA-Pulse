System Capabilities

Everything you need to
control your firmware.

OTA Fetch

Fetch latest OTA metadata for any supported device model — not just your own.

Download Manager

Built-in downloader with pause, resume, retry, and 3× auto-retry on CDN failures.

Payload Extractor

Extract specific partitions like boot.img directly from the payload.bin inside the OTA ZIP.

Secure API Calls

AES + RSA encrypted OTA API communication for all requests mirroring BBK servers.

Device Info

View Android version, security patch level, build number, OTA size, and accurate MD5 hashes.

Background Extraction

WorkManager ensures reliable background downloads and extraction — even when minimized.

In-app Updates

Auto-detects new OTA Pulse releases via GitHub API so you're always up to date automatically.

Material You

Full Material Design 3 implementation with system-wide dynamic color support on Android 12+.
